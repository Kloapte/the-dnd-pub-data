# Core Rules Foundation Phase 5 Rule Gap Inventory

## Status and scope

Structural inventory covers all 231 records in `src/main/resources/data/variantrules.json`, collection `$.variantrule`. It records source identity, source metadata fields, reprint data, `ruleType`, source-entry roots, and nested text-leaf paths. The original conversion/accounting checkpoint remains 28 interpreted/accounted records and 203 PENDING conversion records; those dispositions are preserved unchanged. The completed semantic-discovery checkpoint records 231 REVIEWED and 0 PENDING records. Semantic review status is not canonical conversion status. The approved Rule schema was not changed.

Reviewed Rule outcomes are 11 FULL, 5 PARTIAL, and 12 UNSUPPORTED across 28 records (five Phase 3/4 representatives and 23 Phase 5 records). There are 14 canonical Rule outputs: five Phase 3/4 and nine Phase 5. The 203 pending records are excluded from these outcome totals.
