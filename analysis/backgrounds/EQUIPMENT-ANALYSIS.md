# Background Equipment Analysis

`startingEquipment` occurs on 144 roots. It is a list of equipment packages; each package preserves named alternatives (`a`/`b`, `A`/`B`, and once `a`–`d`) or `_` fixed contents. Contents distinguish UID strings, item UID objects, special/free-text equipment, equipment-type references, and monetary values. Object metadata includes optional `quantity`, `displayName`, `containsValue`, and `worthValue`. The implementation retains package boundaries and each entry variant; no flattening or inventory application occurs.

Item UID references are parsed only from explicit source UIDs and resolved against Item Catalog by exact source-aware identity. If the source omits a source component and the name has multiple catalog matches, resolution is marked ambiguous. Unmatched explicit UIDs remain unresolved. `special` descriptions remain text-only equipment descriptors. Currency is represented as an explicit value grant in copper pieces, distinct from item price and from a pouch/container's `containsValue`.

The typed analyzer records four statuses: resolved item reference, unresolved item reference, ambiguous item reference, and text-only descriptor. The normalized catalog has **718 resolved**, **8 unresolved**, **0 ambiguous**, and **204 text/equipment-type** entries, including inherited equipment on copies. The unresolved entries are occurrences of three UIDs: `holy symbol|phb`, `holy symbol|xphb`, and `arcane focus|xphb`. Counts are asserted by `BackgroundPipelineTests`. No Item definitions are added, and neither Loot nor Magic Variants is imported.
