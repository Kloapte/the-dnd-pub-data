## Existing canonical model and gaps

The baseline model already provides `AttackRollMechanic`, `SpellTargetSubject` with
`SINGLE_TARGET_CREATURE`, `DamageMechanic`, `CharacterLevelDamageScaling`,
`AppliesOnAttackRollOutcome`, `AppliesForDuration`, `UntilTurnBoundary`, and turn actors `CASTER` and
`AFFECTED_SUBJECT`. These represent the two one-roll attacks, hit damage and scaling, and the two
effect durations without a combat engine. `StatisticModifierMechanic` can represent numeric changes
to `ATTACK_ROLL`, but no canonical type represents advantage or disadvantage. Existing
`ApplicabilityCondition` values do not express “target is undead” or “target wears armor made of
metal.” `ReactionActivationMechanic` describes spending a reaction to activate an effect; it does
not mean that a target is unable to take reactions. No payload represents prevention of hit point
recovery.

`AppliesOnAttackRollOutcome` expresses a one-way, revision-bound dependency from a dependent claim
to its attack-roll claim. Its validator currently permits only damage and numeric statistic-modifier
payloads, so it must also accept any new typed prevention payloads used by these candidates. There
is no reverse effect dependency on `AttackRollMechanic`, and none will be added. No target-category
predicate or equipment predicate currently provides a safe representation for the conditional
undead and metal-armor rules.

## Eligibility decision before implementation

The two candidates are independently suitable for bounded extraction if each receives an
evidence-backed unsupported diagnostic for its unrepresentable secondary modifier. Existing attack,
damage and character-level scaling semantics fit. Add only two narrowly typed payloads if the model
review is confirmed in implementation: hit point recovery prevention and reaction prevention. Bind
each prevention claim to the correct attack revision and `HIT`, with its source-specified turn
boundary. Do not represent either prohibition as damage, a condition or a numeric modifier. Leave
Chill Touch's undead disadvantage and Shocking Grasp's metal-armor attack advantage as distinct,
source-evidenced unsupported constructs unless a semantically precise existing model is found.

The metal-armor condition applies to the attack roll before its outcome; it must not be attached to
the `HIT` binding. The undead-target condition changes disadvantage on rolls that the affected
undead creature makes against the caster, not a numeric attack modifier on Chill Touch's attack
roll. Neither is representable without adding roll-quality and target-predicate semantics, which are
outside this bounded batch.

## Implementation and verification

The production change adds two immutable, zero-field payload types:
`HitPointRecoveryPreventionMechanic` and `ReactionPreventionMechanic`. Their family values are
`HEALING_PREVENTION` and `REACTION_RESTRICTION`. `AppliesOnAttackRollOutcome` now accepts these
payloads as one-way dependents; the attack-roll claims contain no reverse effect bindings. Existing
duration and turn-boundary types are reused. No generic predicate or advantage/disadvantage model
was added.

`PhbSpellAttackRules` uses the existing shared one-roll extraction path for both PHB owners. Each
emits one `CASTER` attack at cast time against one creature, a separate HIT-bound damage claim with
character-level tiers at levels 1, 5, 11, and 17, and a HIT-bound effect claim with the source's
duration. Chill Touch's prevention ends at the start of the caster's next turn; Shocking Grasp's
reaction restriction ends at the start of the affected subject's next turn. The ghostly hand phrase
is part of Chill Touch's duration description and is not emitted as a separate mechanic.
