All 969 records have `name`, `source`, `page`, `level`, `school`, `time`, `range`, `duration`, `components`, and `entries`. Every source root has a distinct primary `(name, source)` pair. Source and edition are record data, not inferred from the filename. Additional source metadata occurs on records (`additionalSources`, `otherSources`, `referenceSources`, `reprintedAs`) and is inventoried separately; it does not add spell roots.

The 148-path inventory includes every recursively observed root and nested path, JSON type counts, field occurrence counts, optionality relative to observed parent nodes, structural variants, source-file distribution, and an advisory semantic category. The corpus contains no explicit JSON null values. Paths ending in `[]` count array elements; a missing child there can mean an empty array, so that value is not equivalent to an absent property. Root spell `entries` are recursively typed strings and structured objects, including nested lists and tables; those are descriptive/source entry shapes, not additional spells.

The repository already has spell DTE and entry mapping code and earlier schema reports. They predate this discovery task and were not changed; this report is source analysis, not a claim that the full proposed spell domain or API exists.
