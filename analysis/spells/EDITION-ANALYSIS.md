# Edition analysis

The available PHB and XPHB roots are separate primary-source definitions: 361 PHB and 391 XPHB. There are 359 same-name pairs across those sources. Keep separate IDs even where `reprintedAs` connects one to the other. Other sources also contain same-name records (386 cross-source name groups in total), so edition is only one example of source-aware identity being essential.

The source data itself carries edition differences in level/school and casting metadata; exact differences must remain attached to each definition. Plant Growth is an example where both PHB and XPHB have two casting time entries and the XPHB entries add distinct notes. XPHB reprint links explicitly mark relationships where supplied. Do not impose XPHB data onto PHB roots or infer a reprint edge for every identical name.

Edition should not be inferred from spell level, source filename alone, or a globally familiar name. Preserve original source codes and explicit source relationships; apply no rules conversion during normalization.
